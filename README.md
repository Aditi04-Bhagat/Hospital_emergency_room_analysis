# Hospital Emergency Room Dashboard

## Project Overview

This project focuses on analyzing **Hospital Emergency Room (ER) data** using Excel and Power BI. The dashboard provides an interactive view of emergency room performance by analyzing patient visits, waiting times, satisfaction scores, admission status, and department-level trends.

The goal of the project is to transform raw healthcare data into meaningful insights that can help understand **patient flow, operational performance, and service quality**.

## Tools & Technologies

* Microsoft Excel
* Power BI
* Power Query
* Data Cleaning & Transformation
* Data Visualization

## Key Metrics Analyzed

* Total number of patients
* Average patient waiting time
* Patient satisfaction score
* Admission vs. non-admission
* Patient visits by department
* Patient demographics
* Patient flow and operational trends

## Dashboard Features

* Interactive KPI cards
* Patient visit analysis
* Waiting time analysis
* Patient satisfaction analysis
* Admission status breakdown
* Department-wise analysis
* Interactive filters and slicers
* Charts and visualizations for identifying trends

## Key Insights

The dashboard helps identify patterns in **patient volume, waiting times, satisfaction levels, and admission rates**. These insights can be used to better understand emergency room operations and areas that may require further attention.
